# CI 摩擦检查清单

当 CI/评审正在拖慢团队时，使用这份清单。

## 摩擦信号
- [ ] CI 明显比本地冒烟路径慢很多
- [ ] 同一个不稳定检查反复失败
- [ ] 开发者在不理解失败任务的情况下就合并
- [ ] 评审者花时间指出可重复出现的问题
- [ ] 安全检查只在流水线后期失败
- [ ] 日志噪音很大，难以快速扫描
- [ ] 一个失败会阻塞无关工作

## 最小但高杠杆的修复项
- [ ] 添加一个与最有价值 CI 子集相匹配的本地冒烟命令
- [ ] 将慢任务与快速门禁任务拆分开
- [ ] 缓存依赖和构建产物
- [ ] 将不稳定测试隔离，并指定负责人和截止日期
- [ ] 改进失败摘要，让首个错误一眼可见
- [ ] 将安全或策略检查前移
- [ ] 为高风险变更添加 PR 模板提示
