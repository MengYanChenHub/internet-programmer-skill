# 黄金路径检查清单

如果一个项目能让一位压力很大但能力合格的开发者迅速进入有效产出状态，那么它就通过了黄金路径测试。

## 搭建
- [ ] 存在一条命令完成本地环境搭建的方式
- [ ] 必需版本已被固定
- [ ] 预检失败足够快，且错误信息有用
- [ ] 提供了种子数据 / 示例环境

## 反馈回路
- [ ] 文档中写明了最小但有用的测试命令
- [ ] 存在 watch 模式或快速迭代路径
- [ ] 文档链接到了常见失败模式

## 可见性
- [ ] 日志足够结构化，便于检查行为
- [ ] 无需猜测即可检查运行时状态
- [ ] 网络/API 故障可追踪

## 文档
- [ ] README 包含已验证可用的快速开始
- [ ] 命令可安全复制粘贴
- [ ] 存在故障排查章节
- [ ] 记录了上次验证日期

## 安全性
- [ ] 反复出现的错误已通过 CI 或 pre-commit 自动规避
- [ ] 评审预期清晰明确
- [ ] 安全检查足够早发生，以避免后期反复返工
